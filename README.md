# 김현아 포트폴리오

UX/UI 디자인과 웹 퍼블리싱 작업을 소개하는 정적 웹사이트입니다.

## 파일 구성

- `index.html`: 메인 포트폴리오
- `projects/`: ROM&ND, NODA 상세 페이지
- `css/`: 공통 스타일, 화면 스타일과 인터랙션 스타일
- `js/`: 갤러리, 미리보기와 인터랙션 스크립트
- `assets/images/`: 실제 사용 중인 이미지와 파비콘
- `robots.txt`, `sitemap.xml`: 검색 엔진 설정

## 로컬 미리보기

프로젝트 폴더에서 `python -m http.server 8765`를 실행한 뒤
`http://127.0.0.1:8765/`에 접속합니다.

메인과 상세 페이지의 실제 프로젝트 미리보기는 인터넷 연결이 필요합니다.
SEO 주소는 `https://hyeona.vercel.app/` 기준입니다.
